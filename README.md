# Booking API — Система бронирования переговорных комнат

REST API для коворкинга: пользователи просматривают список переговорных комнат, ищут свободные интервалы и бронируют их на нужное время. Система автоматически проверяет пересечения.  
Администраторы управляют списком комнат и могут отменять любые бронирования. Пользователи оставляют отзывы и видят средний рейтинг.

**Аналоги в реальной жизни**: системы бронирования в офисах, часть функционала Calendly, Airbnb, Booking.com, YClients.

## Текущий статус проекта

**Этап 4 завершён** (продвинутый функционал)

- Полная JWT-аутентификация (регистрация, вход, выход)
- Роли: `user` (обычный) и `admin`
- CRUD ресурсов (переговорные комнаты) — только админ может создавать/редактировать/удалять
- Создание бронирования с проверкой пересечения времени (409 Conflict при занятости)
- Отмена бронирования (только своё или любое — для админа)
- Просмотр своих бронирований + фильтры/сортировка/пагинация
- Расписание ресурса на день/неделю
- Поиск свободных ресурсов на заданную дату и время с фильтрами
- Отзывы после завершения бронирования + средний рейтинг ресурса
- Единые правила списков: пагинация, фильтрация, сортировка

## Стек технологий

- PHP 8.2+
- Laravel 11/12
- MySQL / MariaDB
- JWT-аутентификация (tymon/jwt-auth ^2.3)
- Composer

## Установка и запуск (для проверяющего)

1. Клонировать репозиторий  
   ```bash
   git clone https://github.com/Ezhevskiy/practice-backend-2026.git
   cd practice-backend-2026

Установить зависимости
Bash
composer install

Скопировать .env и сгенерировать ключ приложения
Bash
copy .env.example .env
php artisan key:generate

Сгенерировать секретный ключ JWT (обязательно!)
Bash
php artisan jwt:secret

Настроить подключение к базе данных в .env
Пример для XAMPP:textDB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=booking_api
DB_USERNAME=root
DB_PASSWORD=

Создать базу данных booking_api (через phpMyAdmin или консоль MySQL)

Выполнить миграции и добавить тестового админа

Bash
php artisan migrate

php artisan db:seed --class=AdminSeeder

Запустить сервер
Bash
php artisan serve

API будет доступно по адресу: http://127.0.0.1:8000/api

Коллекция доступна в репозитории (или импортируйте из предыдущих сообщений).
Основной сценарий:

Логин как админ → POST /api/login
Создать комнату → POST /api/resources
Поиск свободных → GET /api/resources/available?date=2026-03-20&time_from=14:00&time_to=15:00
Логин как обычный пользователь
Создать бронирование → POST /api/bookings
Повторить → 409 Conflict
Посмотреть свои бронирования → GET /api/bookings
Отменить → DELETE /api/bookings/{id}
Оставить отзыв → POST /api/reviews
Посмотреть отзывы и рейтинг → GET /api/resources/{id}/reviews

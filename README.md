# Booking API — Система бронирования переговорных комнат

REST API для коворкинга: пользователи просматривают список переговорных комнат, ищут свободные интервалы и бронируют их на нужное время. Система автоматически проверяет пересечения.  
Администраторы управляют списком комнат и могут отменять любые бронирования. Пользователи оставляют отзывы и видят средний рейтинг.

**Аналоги в реальной жизни**: системы бронирования в офисах, часть функционала Calendly, Airbnb, Booking.com, YClients.

## Текущий статус проекта

**Этап 5 завершен** (Тесты, Swagger, Docker).

Быстрый запуск (Docker)
Проект полностью упакован в контейнеры. Вам не нужно устанавливать PHP, MySQL или Composer локально.

Клонируйте репозиторий:

Bash
git clone https://github.com/Ezhevskiy/practice-backend-2026.git
cd practice-backend-2026
Запустите проект:

Bash
docker-compose up -d --build
Что произойдет автоматически:

Поднимется контейнер с PHP 8.2 и MySQL 8.0.

Установятся все зависимости через Composer.

Выполнятся миграции и сидеры, включая тестового администратора.

Сгенерируются ключи приложения и JWT.

Доступы:

API: http://localhost:8000/api

Swagger UI: http://localhost:8000/api/documentation

Порт БД: 3307 (внешний).

Реализованный функционал
Пользователи и доступ
JWT-авторизация: регистрация, логин и защищенные маршруты.

Ролевая модель:

Admin: управление ресурсами (CRUD) и отмена любых бронирований.

User: поиск, бронирование и управление своими записями.

Ресурсы и бронирование
CRUD ресурсов: создание и редактирование характеристик, таких как вместимость и оборудование.

Умное бронирование: автоматическая проверка пересечений интервалов времени для защиты от наложений.

Расписание: просмотр занятости ресурса на день или неделю.

Поиск: фильтрация свободных ресурсов по дате, времени и характеристикам.

Отзывы
Возможность оставить оценку и текстовый отзыв после завершения времени брони.

Автоматический расчет среднего рейтинга ресурса.

Тестирование и документация
Автотесты
В проекте реализованы функциональные тесты, покрывающие критическую бизнес-логику. Для запуска выполните:

Bash
docker exec booking-api-app-1 php artisan test
Основные тесты:

Проверка конфликта пересекающихся интервалов времени.

Проверка прав доступа (Admin против User).

Создание и отмена бронирования.

Документация (Swagger)
Интерактивная документация доступна по адресу http://localhost:8000/api/documentation. В интерфейсе можно протестировать все эндпоинты непосредственно из браузера.

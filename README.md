# Booking API — Система бронирования переговорных комнат в коворкинге

**Стек:** Laravel + MySQL + JWT

**Предметная область:** бронирование переговорных комнат в коворкинге  
Пользователи бронируют комнаты на время, система проверяет пересечения интервалов, админы управляют комнатами, после использования можно оставить отзыв.

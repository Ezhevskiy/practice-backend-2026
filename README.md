# Booking API — Система бронирования переговорных комнат

REST API для бронирования переговорных комнат в коворкинге.  
Пользователи могут просматривать комнаты и бронировать их на определённое время, система проверяет пересечения интервалов. Администраторы управляют списком комнат.

## Текущий статус проекта

**Этап 2 завершён** (авторизация + базовый CRUD ресурсов)

- Аутентификация через JWT (регистрация, логин, выход)
- Разграничение ролей: `user` и `admin`
- Полный CRUD для ресурсов (переговорных комнат) — только админ может создавать/редактировать/удалять
- Обычные пользователи могут только просматривать список и детали комнат
- Тестовый админ: `admin@example.com / admin123`

## Стек

- PHP 8.2+
- Laravel 11/12
- MySQL / MariaDB
- JWT-аутентификация (tymon/jwt-auth ^2.3)
- Composer для зависимостей
